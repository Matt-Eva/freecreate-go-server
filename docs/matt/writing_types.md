# Writing Types

This document serves as an overview of the various writing types - and methods for categorizing them - on the platform

## Core Writing Types

- Fiction
- Essays and Blogs
- Poetry
- Memoir and Autobiography

We do not yet offer any sort of "Non-Fiction" or "Journalism" category, as we don't have the capacity for fact checking yet. Instead, everything offered is either creative, experiential, or opinion based.

## Fiction

There are four formats for fiction:

1. Short Stories
2. Novelettes
3. Novellas
4. Novels

Short Stories - approximately 1-15,000 words.

Novelettes - approximately 15,000 - 30,000 words.

Novellas - approximately 30,000 - 50,000 words.

Novels - 50,000+ words.
